# 北森测评题库

把 `2025北森测评题库（最新完整版.）.pdf` 解析成结构化题库，并提供一个可以
**随机、不重复滚动遍历**全部题目的本地练习网站。

- **725 道题**，来自 352 页 PDF
- 文字选择题结构化完整率 **574 / 574 = 100%**
- 图片选项题结构化完整率 **151 / 151 = 100%**
- 一轮练习内**保证不重复**（浏览器端实测 152 题 0 重复）

## 快速开始

仓库里已经带了解析好的 `data/questions.json` 和 `data/images/`，
**只想用网站的话可以跳过解析步骤**，直接看「启动网站」。

### 1. 解析 PDF

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r parser/requirements.txt

python parser/parse_pdf.py \
  --input "raw/2025北森测评题库（最新完整版.）.pdf" \
  --out data/questions.json
```

整个流程约 60 秒（其中 30 秒在渲染图片）。想快速迭代解析规则可以加
`--no-images` 跳过图片导出。

### 2. 跑测试

```bash
pytest parser/tests -v
```

### 3. 启动网站

```bash
cd web
npm install
npm run dev          # http://localhost:5173
```

生产构建：

```bash
npm run build && npm run preview
```

`npm run dev` / `npm run build` 会自动执行 `sync-data`，把根目录的 `data/`
复制到 `web/public/data/`，不需要手动搬运。

## 版式勘察结果

写解析器之前先对 PDF 做了抽样，结论与常见的中文题库版式**差别很大**，
这里记下来，便于日后换题库时对照：

| 元素 | 常见写法 | 本 PDF 实际 |
|---|---|---|
| 题号 | `1、` `第1题` | **独占一行的纯数字**，且第 21 页起大面积缺失 |
| 选项 | `A.` `A、` | **`A:选项文本`**（半角冒号） |
| 答案 | `答案：` `参考答案` | **`正确答案:D`**，3 处跨页时退化成裸 `答案:D` |
| 解析 | `解析：` | `解析:`，**空解析是常态**（725 题中 201 题无解析） |

文档分三段：

| 页码 | 章节 | 特点 |
|---|---|---|
| 1–98 | 言语理解推理题 | 纯文字，319 题 |
| 99–263 | 资料分析题 | 题干配图表，选项是文字，254 题 |
| 264–352 | 图形推理题 | **选项本身就是图片**，152 题 |

关键量化发现：

- **垂直间距双峰分布** —— 题内行距 3.2–4.3 pt，题间距 33–34 pt，
  模糊带只占 1.4%。这是切分题块的主要信号。
- 每页右下角 `x0≈469, top≈790` 的 106×32 图片是**页脚水印**，
  必须排除，否则每道题都会挂一张垃圾图。
- 全部 725 道题的答案都是**单个字母 A–E**。这个题库没有多选、判断、
  填空、简答题。

## 解析策略

### 为什么不是纯正则，也不是纯版面

- **纯间距切分**会把「题干 / 图表 / 选项」切成三块 —— 实测切出 924 块，
  而实际只有 725 道题。
- **纯正则**定不出「解析正文」与「下一题题干」的分界：两者之间没有任何
  显式标记，只有版面间距能区分。

所以用**锚点 + 间距混合**：

1. `正确答案:` / `答案:` 作为**闭合锚点**，标志题干与选项结束。
2. 版面**垂直间距 > 15 pt** 判定「解析结束、下一题开始」。
3. 跨页时没有间距可用，改看上一页末行**是否顶到右边界**：
   满行说明段落未完（续接），不满行说明段落收尾（新题）。

### 图片归属规则

一张图属于**它下方第一个「正确答案」行**所在的题。

不用「题块起止区间」是因为图形推理题里有一批题**连题干文字都没有**
（整道题都画在图里），这类题的首个文本行就是 `正确答案:X`，按区间算
会把自己的图全部漏掉、同时让上一题多吃一张。这个 bug 在实现过程中
真实发生过，7 道题丢图；换成答案行分界后恢复到 100%。

### 两类图的不同处理

- **资料分析题**：逐图渲染，题干末尾插入 `[图片N]` 占位，前端渲染 `<img>`。
- **图形推理题**：同页所有图片的并集区域**整块渲染**成一张 PNG，与原书
  视觉一致；`options` 留空，前端提供 A–E 字母按钮作答。

渲染用 PyMuPDF 而非抽取原始图片流（原始流可能带蒙版、或被拆成多个
XObject）。输出做 256 色调色板量化，体积从 76 MB 降到 31 MB，
图表数字仍然清晰可读。

### 归一化的一个坑

全角转半角**不能无脑用 `unicodedata.normalize('NFKC')`** —— NFKC 会把
中文的「，」映射成 ASCII 逗号，正文面目全非。`parser/normalize.py` 里
只做定向映射（字母、数字、冒号），其余字符原样保留；匹配用的文本和
存储用的文本是分开的两份。

## 数据格式

`data/questions.json` 是一个数组，每个元素：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 稳定唯一。章节前缀 + 内容哈希，重跑幂等 |
| `type` | string | `single_choice` / `multiple_choice` / `true_false` / `fill_blank` / `short_answer` |
| `stem` | string | 题干，`[图片N]` 为配图占位符 |
| `options` | array | `[{key, text}]`，图形题为空数组 |
| `answer` | string \| array \| boolean | 单选 `"A"`，多选 `["A","C"]`，判断 `true`/`false` |
| `explanation` | string | 解析，可为空 |
| `sourcePage` | number | PDF 页码（1-based） |
| `tags` | array | 首项是章节名，图形题附加 `"图片选项"` |
| `images` | array | 相对 `data/` 的图片路径 |
| `number` | number \| null | 原书题号，可能为 null |

`id` 不用题号生成 —— 本书题号在每个章节重置、且第 21 页起大面积缺失。

## 网站功能

- **按分类筛选** —— 言语理解 / 资料分析 / 图形推理，多选框过滤，可组合
- **随机滚动遍历** —— 抽奖桶（不放回）策略：
  1. 取当前筛选集的题目 id，Fisher-Yates 洗牌成「牌堆」
  2. 指针每次触底前移 15 道，推入渲染列表
  3. 牌堆发完提示「已完成一轮」，可一键重新洗牌开始新一轮
  4. **一轮之内每题只出现一次**
- **无限滚动** —— `IntersectionObserver` 监听底部哨兵，提前 400 px 预加载
- **作答与判分** —— 点选选项后提交，自动判对错并展开答案与解析；
  也可以不作答直接「显示答案 / 解析」
- **进度与错题本** —— 已练题数、正确/错误次数、错题集合存 `localStorage`，
  刷新不丢；「只看错题」一键筛出错题重练
- **响应式** —— 手机端单栏布局，实测 390 px 宽无横向溢出
- **深色模式** —— 跟随系统

图形推理题没有文字选项，前端提供 **A–E 五个字母按钮**作答。
五个而不是四个，是因为原书在第 264 页有一条说明：
「图形题选项从上往下数，分别为 A，B，C，D，E」。部分题目实际只有四个
图形选项，此时 E 是多余的。

## 已知限制

1. **原书本身有 24 道题选项不足 4 个**（缺 D 项等）。解析器忠实还原，
   没有补齐。
2. **201 道题没有解析** —— 原书 `解析:` 后面就是空的。前端显示
   「原书未提供解析」。
3. **图形推理题的选项没有逐个切开**，是整块截图。原书里选项图是一整条
   竖向位图，可靠切割需要图像分割，误切风险高于收益。
4. **3 处 HTML 标签**混在 PDF 正文里（`<em class="em inline">` 之类），
   已在清洗层剥离并记入告警。
5. 图形题的整块截图偶尔会带进下一行文字的顶部 —— 源 PDF 里图片 bbox
   本身就与文字有重叠。

## 常见问题

**`npm run dev` 报「题库载入失败」**
`data/questions.json` 不存在。先跑解析器，或确认仓库里的 `data/` 没被删。

**解析器报 `ModuleNotFoundError: No module named 'pdfplumber'`**
虚拟环境没激活，或没装依赖：`pip install -r parser/requirements.txt`。

**想换一本 PDF**
`parser/normalize.py` 顶部有一组版面常量（`RIGHT_MARGIN`、`GAP_NEW_BLOCK`、
`FOOTER_TOP`），`parser/segment.py` 顶部有标记正则和章节标题集合。
换书时先跑一遍抽样、确认这两组常量，再跑解析。`data/unmatched.txt`
的条数是判断规则是否失配的第一指标。

**图片太大想压缩**
调 `parser/images.py` 里的 `ZOOM`（默认 2.0）和 `PNG_COLORS`（默认 256）。
